How to use NthTerm

Stack related terminals in one workspace — focus a live session, overview the whole set, and keep metadata, dock tools, and shortcuts within reach.

Install / download

  1. Download the v0.1.0-rc.2 release candidate for your platform (Windows NSIS, or macOS dmg / zip).
  2. Run the installer or open the app from the archive.
  3. On first launch, expect an unsigned-app warning (SmartScreen on Windows, Gatekeeper on macOS). See Unsigned RC.
  4. Install over an existing copy when upgrading — workspace data in AppData stays put.

Create a workspace

Workspaces group related terminals (for example a fictional Studio Stack: API, UI, database, and compose).

  1. In the left rail, choose New Workspace.
  2. Name it and set a working directory when prompted.
  3. Switch workspaces from the rail anytime — each restores its own terminals and layout.
  4. Rename or delete from the sessions sidebar when you are done with a workspace.

NthTerm restores the last active workspace on launch. Invalid saved directories fall back to your home directory.

Add terminals

Each workspace holds up to 10 stacked terminals. Inactive sessions stay parked with live PTYs so output keeps flowing while you focus elsewhere.

  • Add Terminal in the toolbar — or Ctrl+T / Ctrl+Shift+D.
  • Pick a shell (app default, workspace profile, or an installed WSL distro on Windows).
  • Rename terminals so command history stays attributed after renames.
  • Close the focused terminal with Ctrl+W (live processes get a close warning).

Focus vs Overview

Focus

One interactive terminal fills the stage. Use this when you need full input — for example debugging an API while other stack members keep running behind you.

Overview

Preview cards for the whole stack (up to 10). Arrow keys move between cards; Enter focuses the selected terminal. Stack navigation chrome hides when a workspace has only one terminal.

  • Toggle with the Focus / Overview control, or Ctrl+\.
  • Esc leaves Overview and returns to Focus.
  • Cycle terminals: Ctrl+Tab, Ctrl+[ / Ctrl+], or jump with Ctrl+1–9 / Ctrl+0.

Inspector

The right rail shows compact facts for the active workspace or the focused terminal — status, shell profile, directory, and restart / stop / kill actions for the live session under focus.

  • Switch between Workspace and Terminal views in the inspector header.
  • Hide or show the rail from Appearance preferences; the preference persists locally.
  • In compact windows the inspector becomes an on-demand overlay so the terminal keeps width.

Workspace dock

The bottom dock is a shared review surface: output, problems, search, command history, plus system monitor and session environment when you need them.

  • Toggle the dock with Ctrl+J (visibility and height are remembered per workspace).
  • Visibility defaults on; turn the utility panels off in Appearance if you want a quieter shell.
  • Resize the dock; height stays capped relative to the viewport in compact layouts.

Keyboard shortcuts

Shortcut Action
Ctrl+Shift+P Command palette
Ctrl+Shift+F Global workspace search
Ctrl+T / Ctrl+Shift+D New / add terminal
Ctrl+W Close focused terminal
Ctrl+Tab / Ctrl+Shift+Tab Cycle terminals
Ctrl+Alt+Left / Ctrl+Alt+Right Cycle terminals
Ctrl+[ / Ctrl+] Previous / next terminal
Ctrl+1–9 / Ctrl+0 Jump to terminal 1–10
Ctrl+\ Toggle terminal overview
Esc Leave overview → focus
Arrow keys + Enter Move among overview cards; focus selection
Ctrl+J Toggle workspace dock

On macOS, use Cmd in place of Ctrl where the desktop shell maps accelerators to the platform modifier.

Unsigned RC note

0.1.0-rc.2 is intentionally unsigned. Windows SmartScreen and macOS Gatekeeper may warn on first launch until Authenticode signing and Apple notarization are enabled.

  • Windows: Choose “More info” → “Run anyway” when SmartScreen blocks the installer or app.
  • macOS: Open from Finder and confirm, or clear quarantine for a local smoke path as documented in the repo README (npm run smoke:mac).
  • This is expected for the public RC — not a corrupted download.
